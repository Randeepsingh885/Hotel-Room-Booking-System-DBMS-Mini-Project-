# Hotel Room Booking System (DBMS Mini Project)

**Submitted by:** Randeep Singh (UID 25BCD10148)
**Submitted to:** Mrs. Harkamal Kaur, Assistant Professor
**University:** Chandigarh University

A relational database for hotel room reservation: guests, room types, rooms, bookings and payments.

## Files
| File | Purpose |
|---|---|
| `schema_and_data.sql` | Creates `hotel_booking_db`, all 5 tables and the sample data |
| `queries.sql` | Join, GROUP BY / HAVING, sub-query, UPDATE, DELETE and VIEW examples |
| `DBMS_Mini_Project_Hotel_Room_Booking_System.docx` | Project report |

## How to run (MySQL)
```
mysql -u root -p < schema_and_data.sql
mysql -u root -p < queries.sql
```

## Tables
`guests`, `room_types`, `rooms`, `bookings`, `payments` (+ view `booking_summary`)

## Tools
MySQL, SQL (DDL/DML/DQL), Git and GitHub
